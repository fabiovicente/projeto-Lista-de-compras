# Projeto: Gerenciador de Lista de Compras

---

### **Visão Geral**

Este é um projeto de console desenvolvido em Java para gerenciar uma lista de compras. A aplicação foi criada para ser funcional e robusta, com foco na aplicação de conceitos de Programação Orientada a Objetos e persistência de dados.

---

### **Funcionalidades**

- **Adicionar Item:** Inclui itens com nome, quantidade e preço.
- **Visualizar Lista:** Exibe a lista completa de itens, formatada de forma clara.
- **Remover Item:** Permite a remoção de itens com base em seu número na lista.
- **Calcular Custo Total:** Soma o custo de todos os itens, exibindo o valor total.
- **Persistência de Dados:** Salva a lista de compras em um arquivo de texto, garantindo que os dados sejam mantidos entre as sessões do programa.

---

### **Tecnologias e Conceitos Aplicados**

- **Java:** Linguagem de programação principal.
- **Programação Orientada a Objetos (POO):** Uso de uma classe `ItemDeCompra` para encapsular e organizar os dados.
- **Manipulação de Arquivos (I/O):** Utilização das classes `FileWriter`, `PrintWriter`, `FileReader` e `BufferedReader`.
- **Coleções:** `ArrayList` para gerenciar a lista de forma dinâmica.
- **Tratamento de Exceções:** Blocos `try-catch` para lidar com erros de entrada do usuário.

---

### **Como Executar o Projeto**

1.  **Pré-requisitos:** Certifique-se de ter o [Java Development Kit (JDK)](https://www.oracle.com/java/technologies/downloads/) instalado em sua máquina.
2.  **Clonar o Repositório:** Abra seu terminal e execute o comando:
    `git clone https://www.youtube.com/watch?v=GRf6so_sois`
3.  **Abrir e Executar:** Abra o projeto no IntelliJ IDEA e execute o método `main` na classe `ListaDeComprasApp.java`.
